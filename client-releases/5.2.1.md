GymPASS 5.2.1 reserva la gestión de respaldos al superadministrador.

- Los administradores de gimnasio dejan de ver el apartado Respaldos en la página y en las aplicaciones.
- Las API rechazan sus solicitudes de creación, consulta, descarga, importación, restauración y configuración de respaldos.
- El panel del superadministrador ofrece «Respaldos» para cada gimnasio: crear, descargar, importar y restaurar con confirmación de contraseña.
- Se valida que cada copia pertenezca al gimnasio seleccionado. Los gimnasios suspendidos conservan la creación y consulta; requieren reactivación antes de importar o restaurar.
- Se conservan las copias existentes y las copias automáticas internas de protección.

Incluye APK Android, instalador Windows x64 y portable. Android conserva el paquete y el certificado, con código 5210. Windows requiere Windows 10 o posterior y conserva su distribución sin firma de código.
